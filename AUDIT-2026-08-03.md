**Date:** August 3, 2026
**Scope:** Every page in the application (37 routes)

---

## Executive Summary

The public-facing pages (Homepage, Marketplace, How It Works, About, Login, Signup) are **V2 design** and look solid. The problem is the **dashboard** — out of 13 dashboard pages, only the **Overview** is fully V2. Everything else is still running V1 hardcoded hex colors and inconsistent styling. Functionally it all works, but visually half the app looks polished and the other half doesn't match.

## Critical Issues (Fix Now)

### 1. Logo Rendering
The `logo-new.png` wordmark has "CITY" as a tiny rotated vertical block that looks like a hamburger icon (≡) at small sizes. "FEED" dominates. On dark backgrounds, CSS `filter: invert(1)` makes it white but the proportions are still off.

**Recommendation:** Get a proper logo file from the design team — horizontal wordmark with transparent background, optimized for both light and dark surfaces. Or create a simplified SVG wordmark.

### 2. Bookings List + Detail (HIGH PRIORITY)
These are the most-used pages after Overview and they're still V1. Every color is hardcoded hex (`#f0f0ec`, `#7ecfc0`, `#2b2b2b`). The values happen to match the V2 palette so they *look* right, but they're not using CSS variables, which means:
- Any future theme change requires editing every file
- Subtle inconsistencies creep in
- No dark mode path

### 3. Booking Detail has Duplicate Creative Specs
Both a "Creative Requirements" card and a "Creative Specs" card render similar data. Consolidate into one.

## V1 Pages That Need V2 Migration

These pages are **functional but visually V1** — hardcoded hex colors, no CSS variable usage, inconsistent shadows/borders:

### Tier 1 (User-facing, high traffic)
1. **Bookings List** (`/dashboard/bookings`) — BookingCard component, STATUS_CONFIG, all inline hex

### Tier 3 (Utility pages)

8. **Notifications** (`/dashboard/notifications`) — Clean but hardcoded

## Shared Component Opportunities

Several patterns are duplicated across pages and should be extracted:

1. **Toggle Component** — duplicated inline in Settings, Create Listing, and Booking Detail
2. **Status Badge** — `STATUS_CONFIG` / `STATUS_STYLES` copy-pasted in 4+ files
3. **Card Container** — `rounded-2xl p-6 bg-white border border-[#e0e0d8]` repeated everywhere
4. **Input Style** — `inputStyle` object duplicated in Profile, Create Listing, Settings
5. **Empty State** — Similar empty-state UIs duplicated across Saved, Bookings, Messages
